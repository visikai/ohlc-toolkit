# Window oracle goldens

These files are regenerated byte-for-byte by the test suite. Nothing here
is hand-edited: run

```bash
mise exec -- uv run python -c \
    "from tests.test_windows.synthetic import write_golden_files; \
     write_golden_files()"
```

and a clean tree stays clean. If it does not, the oracle's behaviour
changed and the diff is the review.

## `invalid_*`

`invalid_straddling_1m_rolling_4m_every_2m.csv` is produced from
deliberately malformed input: rows placed off the declared source grid,
overlapping their neighbours. It exists to pin two behaviours that a
strictly valid source can never exercise: whole-candle exclusion at a
window boundary, and unclamped coverage accounting. Its
`coverage_seconds` values exceeding the window duration are intentional,
not a bug in the fixture.
